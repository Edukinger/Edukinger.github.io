# Un pequeño mundo para Chaparrita 🧸

Esta versión abre directamente: **no tiene contraseña ni pantalla de entrada**.

## Archivos
- `index.html`: página principal.
- `styles.css`: diseño adaptable, colores pastel y animaciones.
- `script.js`: interacciones del regalo, carta y deseos.

## Cómo abrir
Puedes abrir `index.html` directamente en tu navegador para probarla.

## Cómo publicar y compartir
1. Sube estos tres archivos a un repositorio de GitHub o arrástralos a Netlify Drop.
2. Publica el sitio.
3. Copia el enlace público que te proporcione Netlify y envíaselo por WhatsApp.

No hay contraseña: cualquiera que tenga el enlace podrá abrir la página.
